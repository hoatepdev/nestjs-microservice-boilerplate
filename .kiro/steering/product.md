# Product Overview

## NestJS Microservice Boilerplate API

A comprehensive NestJS-based microservice API boilerplate implementing clean architecture principles with full-featured user management, authentication, and authorization systems.

### Core Features

- **Authentication & Authorization**: JWT-based auth with role-based access control (RBAC)
- **User Management**: Complete CRUD operations for users, roles, and permissions
- **Multi-Database Support**: Both MongoDB and PostgreSQL with migrations
- **Observability**: Distributed tracing, metrics, and structured logging
- **Security**: Helmet, CORS, input validation, and security best practices
- **Internationalization**: Multi-language support (English/Portuguese)
- **Email System**: Template-based email notifications
- **Caching**: Redis and in-memory caching options
- **API Documentation**: Auto-generated Swagger/OpenAPI documentation

### Architecture

Built using **Onion Architecture** with **Domain-Driven Design (DDD)** and **Ports and Adapters** patterns, ensuring clean separation of concerns and high testability.
